# Design Contract

- Palette (exactly these six colours, nothing else, ever): background #FAFAF8, primary text #1F1F1F, muted text #6B6B63, border #E1DED6, primary accent #2F5233 (dark forest green), warning accent #C98A1E (amber), critical accent #B3262A (red). No blue, indigo, purple, or gradients of any kind, on anything, including metric numbers.
- Fonts: UI text uses system-ui, -apple-system, "Segoe UI", sans-serif. Anything numeric or identifier-like — plate numbers, coordinates, timestamps, scores, IDs — uses a monospace stack: ui-monospace, "SF Mono", "Cascadia Mono", Consolas, monospace. Do not use Inter, Roboto, or Arial as a deliberate choice — if a browser falls back to one of these because nothing else is installed, that's fine, but don't name them in the stack.
- Shape: border-radius maximum 4px, anywhere. No glassmorphism, no backdrop-filter blur, no drop shadows — 1px solid borders in the border colour separate every section.
- Motion: only opacity or background-colour transitions, 150ms or less, ease timing. No bounce, no spring, no elastic overshoot curves, no skeleton shimmer, no auto-playing anything.
- Data display: real HTML tables for anything tabular. Never a grid of icon-plus-heading-plus-two-lines cards — that specific pattern (three or six identical cards in a row) is one of the most recognisable "an AI built this" tells and is banned outright here.
- Tone of all written copy (README, UI labels, empty states, docs): plain and factual. State what a thing does in one sentence. No adjectives that don't carry information ("powerful," "seamless," "robust," "cutting-edge," "innovative"). No sentences that exist only to sound impressive. This gets enforced concretely in Stage 9's README pass, but it applies to every piece of UI copy from Stage 7 onward too.
